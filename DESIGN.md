# Zero Hour Web visual system

Operate mode for setup and rooms; Experience mode for gameplay. A printed operational field manual informs the composition: dark olive paper and pale ink by default, with an optional warm off-white paper theme, olive controls, rust error text, precise rules and generous grouping. The game occupies a black stage with a collapsible utility bar that reserves space when shown. No desktop metaphor. Readiness uses plain language rather than ornamental badges.

Display lettering uses the bundled open-source Rajdhani face; body copy uses native readable sans. Controls have explicit loading, disabled, focus and error states. Motion is a brief clipped page reveal and respects reduced motion. Desktop is the playable target; narrow screens retain account/library controls and explain the desktop requirement.
