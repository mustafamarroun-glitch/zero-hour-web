    Take the field on desktop

    Use Windows Chrome with hardware acceleration enabled. Mac gameplay is under investigation; mobile supports setup.

    Left-click selects. Right-click issues movement or attack orders. Drag a selection box for groups. Choose a builder, then use the construction panel. Esc opens the game menu.

    F8 shows or hides the website toolbar. Alt + Enter toggles fullscreen. Move the cursor to the battlefield edge to scroll the camera. Click the battlefield to return keyboard control after using settings.

    The toolbar hides automatically. Settings offers resolution, display size, music and effects volume, edge scrolling and diagnostics. Higher resolutions need more graphics power.
