Prepare ShockWave.

The browser needs your compatible Zero Hour base archives and the official ShockWave 1.201 archives together. The downloaded ZIP containing the Windows installer is not a browser package.

  1. Use a separate copy of your Zero Hour files for the mod. Keep your working Zero Hour installation available.
  2. Install or extract the official ShockWave 1.201 package into that separate copy. Keep the eleven active mod archives; original .gib files and activated .big files are accepted. Leave optional classic icons disabled.
  3. Open ShockWave and import the prepared folder, or a ZIP/RAR containing its base and mod archives. The launcher checks the mod version before saving it.

This browser profile uses the project’s compatible combined base archive set. Use the same prepared files on both players’ devices. Allow around 3 GB of browser storage.

The native GenTool, wrapper, SWR.net launcher and DLL files are not used by the browser engine. Keep Patch 1.06 and other gameplay mods out of this package. ShockWave is built on the Zero Hour 1.04 rules.

Your settings, imported files and saved games use a separate ShockWave storage area. Zero Hour and Yuri remain available from the game navigation.
