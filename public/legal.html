Version 3.0 rebuilds the ZeroHour engine with a browser replay recorder patch; the corresponding-source ZIP contains the patch, build instructions and pinned source/compiler/artifact manifest.

Browser RAR decoding uses node-unrar-js 2.0.2 (MIT adapter) and UnRAR 6.1.7 (UnRAR license); native decoder source is retained. Rajdhani is distributed under the SIL Open Font License.

Retail game data is supplied by each player and processed locally. Commander names and private-room compatibility metadata are sent to the room service. Signaling carries encrypted peer negotiation; game traffic uses WebRTC data channels. Names are display names, not authenticated accounts. Room state is temporary and held in server memory.

Yuri’s Revenge uses a separate RA2 VM runtime, revision a10ac9899c258b01be1edd80492397e9de225ba5, under GPL-3.0-or-later. Dependency notices and dependency licenses are retained. Engine source and relay source are downloadable. Yuri game traffic uses a separate binary WebSocket relay; player-owned installation files remain local. Its session code selects a virtual LAN and is not authentication.

ShockWave 1.201 is a player-supplied mod by SWR Productions. Its game data is not included in this website or its source downloads. The browser uses the existing New Shoes engine and a separate mod archive and save context; native Windows mod launchers are not executed.
