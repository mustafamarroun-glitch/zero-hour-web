# Zero Hour Web

## Platform
Desktop web, with mobile setup guidance.

## Stack
Delegated by the supplied brief: static HTML/CSS/modules, New Shoes threaded WebAssembly, local OPFS import, a separate Node signaling service.

## Purpose
Open the website, choose Zero Hour or Yuri’s Revenge, enter a commander name, import compatible player-owned files locally, and play through each game’s own runtime and network protocol. Both games share setup, ZIP/RAR/folder import, installed-file recovery, ZIP backup, settings and room controls. Yuri uses its original Network lobby after launch.

Stream game also connects a guest to an independent Zero Hour session on the
host laptop. A private HTTPS invite works through a running Internet tunnel;
the guest receives video/audio and sends controls without importing game files.
The host retains assets, imports and saves. Remote performance requires an
actual separate-device test.

## Constraints
Username-only guest identity; no account authentication. Original installations and Online-Games remain untouched. Retail archives stay local and are excluded from source and deployment. No automatic patches, mods, or substitute data. Mac gameplay and cross-network matches require independent acceptance.

## Visual commitment
Original military direction, clear typography, restrained motion, immediate play flow, no OS desktop. The game selector adds Yuri’s Revenge within the existing visual system. Chrono Divide is a player-journey reference only.
